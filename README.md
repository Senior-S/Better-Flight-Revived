# Better Flight Revived

Better Flight Revived is a modern 1.21.1 revival of the old [Better Flight Forge](https://www.curseforge.com/minecraft/mc-mods/better-flight-forge) mod.

It improves vanilla Elytra flight with takeoff, flapping, flaring, stamina, HUD feedback, and compatibility with popular equipment-slot mods. The goal is to keep Elytra movement fun and skill-based while reducing the need to burn through fireworks for every flight.

[![](https://dcbadge.limes.pink/api/server/https://discord.gg/6c6cDU2mKj)](https://discord.gg/6c6cDU2mKj)

## Features

- Sprint and double-jump to take off with Elytra.
- Flap your wings for controlled lift and momentum.
- Modern boost mode for stronger near-ground launches.
- Hold `X` while flying to flare your wings and slow down for easier landings.
- Flight stamina meter with Elytra durability feedback.
- Configurable stamina costs, recharge timing, hunger exhaustion, ceiling limits, and additional wing items.
- Cross-loader support for Fabric and NeoForge on Minecraft 1.21.1.

## Installation

This mod requires Minecraft 1.21.1 and Java 21.

### Fabric

Required libraries:

- [Fabric Loader](https://fabricmc.net/use/installer/) 0.19.2 or newer
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Architectury API](https://modrinth.com/mod/architectury-api) 13.0.8 or newer

Optional compatibility:

- [Trinkets](https://modrinth.com/mod/trinkets) 3.10.0 or newer
- [Beans Backpacks 3](https://modrinth.com/mod/beans-backpacks-3) 0.12 or newer

### NeoForge

Required libraries:

- [NeoForge](https://neoforged.net/) 21.1 or newer
- [Architectury API](https://modrinth.com/mod/architectury-api) 13.0.8 or newer

Optional compatibility:

- [Curios API](https://modrinth.com/mod/curios) 9.5.1 or newer
- [Beans Backpacks 3](https://modrinth.com/mod/beans-backpacks-3) 0.12 or newer
